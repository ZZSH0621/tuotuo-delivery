## 版本与功能

本包基于提交 `aa61b5dc3a4f4944ac30105b121794a04bc4eb7c` 的 v20 源码公开清理版，包含粉黑界面、角色素材、6 段提醒音效、工作留痕、备忘录、倒计时屏保、电脑端桌面/390px 手机竖屏布局切换，以及个人 OpenAI API 密钥转录入口代码。

截至 2026-10-31：v20 已保存，**尚未部署到生产网站，生产仍为 v18**。API 默认关闭，未进行真实付费语音转录验收。每个人使用自己的密钥与额度，不含共享密钥；当前仅支持指定的 OpenAI 语音转录模型，不支持任意聊天模型或服务商地址。

## 与原始完整交付包的区别

此公开包已移除内部部署标识、私有文件引用、许可尚未核实的转换语音模型权重及 FLEURS 测试音频。因此它**不是包含本地语音模型的完整离线识别包**，本地识别不能开箱即用。图片、音效和代码保留，第三方 notices 随包提供。本仓库不额外授予整项目或用户素材的开源许可。
