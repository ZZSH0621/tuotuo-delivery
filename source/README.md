# TUOTUO 妥妥 · 照护工作搭子

当前公共源码快照对应线上 **v49**（2026-10-31）。

## 运行

需要 Node.js 22.13.0 或更新版本。

```sh
npm ci
npm run dev
```

生产构建执行 `npm run build`，构建后可执行 `npm start`。运行地址以终端输出为准，工作台在 `/legacy/`。

## 服务端配置

按 `.env.example` 配置运行环境；本地预览使用 Cloudflare Worker 支持的 `.dev.vars`，生产在托管平台设置环境变量和 Secret。

| 变量 | 说明 |
| --- | --- |
| `API_TRANSCRIPTION_ENABLED` | 启用云端转写时设置为 `true` |
| `API_EXPECTED_ORIGIN` | 当前站点 HTTPS Origin，不带末尾斜杠 |
| `DASHSCOPE_API_KEY` | 在服务端设置自己的百炼 Secret；公开源码不含实际值 |
| `ASR_PROVIDER` | 默认 `bailian-cn`（北京） |
| `ASR_WORKSPACE` | 使用专属工作空间域名时填写，否则留空 |

本地 HTTP 用于界面预览；云端 ASR 需要 Origin 配置匹配的 HTTPS 站点。

新建 Sites 应用时，应将 `.openai/hosting.json` 的 `project_id` 绑定到自己的应用；源码中的原站标识仅记录源项目。框架与其他平台迁移说明见 `docs/VINEXT_STARTER.md`。

## 已集成

- 粉黑手机 UI 与桌面工作台；“我”页 IP 形象。
- 一句话按住录音，松开提交千问 ASR，自动写入留痕；本地规则提取床号、姓名、事项和明确时间。
- 查房／交班长录音按 25 秒分段提交 ASR，结束后由 `qwen3.8-flash` 按床号整理；两种录音分区留痕。
- 待办、最近三个有效定时任务、倒计时、到时消息卡、音效、网页屏保和备忘录。
- 留痕左滑删除、撤销和最近删除恢复。
- 教材搜索界面及模型搜索词解析；需自行恢复授权教材数据。
- 一句话采集恢复为合并 UI 前版本，麦克风按住/松开/转写时保持固定位置。

ASR 使用 `qwen-audio-3.1-asr-flash`；搜索解析和查房整理使用 `qwen3.8-flash`。接口不要求 ChatGPT 登录，不设置应用侧每日预算、次数或频次上限；厂商账户计费与接口容量仍由厂商决定。

## 数据与资源

任务与备忘录只保存在当前浏览器，未接入账号云同步。原始录音不作为任务附件持久化，刷新会丢失录音；查房失败片段可在页面未刷新时重试。网页进入后台、锁屏或关闭后不保证提醒继续运行。

公共源码包含代码、品牌图片、音效与现有第三方 notices。教材全文及扫描页、可选本地 Whisper 转换模型资源不附在公共版；云端 ASR 不依赖这些模型。完整本地交付包仍保留上述资源，公共包不含实际密钥。

源码内第三方素材按各自声明使用；本仓库未新增整项目或用户素材的统一开源许可。
